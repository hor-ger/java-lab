REST API

RESTful végpontok a gépek és szoftverek kezeléséhez. Tesztelhető cURL-lel és Postman-nel.

Alap URL

http://localhost:8080/api

Gépek – /api/gepek

Metódus URL Leírás
GET/api/gepekÖsszes gép listázása
GET/api/gepek/{id}Egy gép lekérése
POST/api/gepekÚj gép létrehozása (JSON body)
PUT/api/gepek/{id}Gép módosítása (JSON body)
DELETE/api/gepek/{id}Gép törlése

Szoftverek – /api/szoftverek

Metódus URL Leírás
GET/api/szoftverekÖsszes szoftver listázása
GET/api/szoftverek/{id}Egy szoftver lekérése
POST/api/szoftverekÚj szoftver létrehozása (JSON body)
PUT/api/szoftverek/{id}Szoftver módosítása (JSON body)
DELETE/api/szoftverek/{id}Szoftver törlése

JSON példa – új gép (POST)

{
  "hely": "T101",
  "tipus": "notebook",
  "ipcim": "192.168.10.50"
}

JSON példa – új szoftver (POST)

{
  "nev": "Visual Studio Code",
  "kategoria": "fejlesztői eszköz"
}

cURL példák

Postman

Postmanben állítsd be a metódust (GET/POST/PUT/DELETE), az URL-t (pl. http://localhost:8080/api/gepek), POST/PUT esetén a Body → raw → JSON mezőt. A válasz JSON formátumban érkezik.
